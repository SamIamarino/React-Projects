# React Studies – Aprendendo um pouco sobre React.

Este repositório é uma coletânea de pequenos projetos desenvolvidos com **React**, voltados para o aprendizado prático de conceitos essenciais, estilização de componentes e lógica de interface, utilizando o curso React-Full-Guide do Maximilian Schwarzmüller.

---

## 📦 Conteúdo do Repositório

### 🧩 1. React Art - Styling with React
Projeto voltado ao aprendizado de diferentes formas de aplicar estilos em componentes React.

**Tópicos abordados:**
- Estilo inline dinâmico
- CSS Modules
- Styled Components

📁 Caminho: `React Art - Styling with React/`

---

### 📄 2. React-Essentials-Page
Uma página simples construída com foco nos fundamentos do React, ideal para iniciantes.

**Tópicos abordados:**
- Criação de componentes funcionais
- Uso de props e state
- Manipulação de eventos
- Renderização condicional

📁 Caminho: `React-Essentials-Page/`

---

### ❌ 3. React-Tic-Tac-Toe
Clássico jogo da velha implementado com React, útil para consolidar lógica de estado e renderização.

**Tópicos abordados:**
- Gerenciamento de estado
- Verificação de vitória
- Componentização e reusabilidade

📁 Caminho: `React-Tic-Tac-Toe/`
